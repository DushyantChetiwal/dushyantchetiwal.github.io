CRATES/ARCHITECTPLAN GRAPH & RUNNER

Interactive Architect Canvas

Model complex tasks as a graph of explicit steps, rules, hand-off captures, conditional branches, and bounded retry loops.

Each step opens in its own refinement chat, declares its anticipated file surface for parallel conflict detection, and checkpoints completed results so interrupted runs resume cleanly without redoing finished work.

  • DAG compiler
  • File-surface validation
  • Checkpoints
  • Plan / Build modes
CRATES/AGENTCONCURRENCY & TOOLS

Worktree Agents & Async Watchers

Spawn parallel sub-agents and plan branches in isolated Git worktrees, then diff and merge clean results back to your workspace.

Long-running terminal commands, CI checks, and background sub-agents run without blocking polls—event-driven watchers automatically wake the parent conversation when work finishes, fails, or needs input.

  • Isolated Git worktrees
  • Non-blocking watchers
  • Native git tools
  • ACP multi-agent
REMOTE-ANDROIDMOBILE CONTROL

Praxis Remote for Android

Operate desktop windows or headless Linux/WSL hosts from your phone over encrypted WebRTC and Nostr relays.

Opens instantly from an on-device SQLite cache, streams updates via Protocol v3 deltas, supports model switching, permission approvals, voice steering, plan/worktree inspection, and headless CLI pairing.

  • Kotlin & Compose
  • Protocol v3 deltas
  • SQLite 0ms cache
  • Headless CLI pairing
RUST / GPUIMULTI-PROVIDER

Native Rust & Open Ecosystem

Built on Zed’s GPU-accelerated GPUI engine with native LLM providers and external Agent Client Protocol (ACP) agents.

Use Gemini, Claude, OpenAI, OpenRouter, or local Ollama models alongside external ACP agents like Cursor, Claude Code, and Codex—plus remote global skills over SSH, WSL, and dev containers.

  • Rust & GPUI
  • Native + ACP agents
  • SSH / WSL skills
  • GPL-3.0
